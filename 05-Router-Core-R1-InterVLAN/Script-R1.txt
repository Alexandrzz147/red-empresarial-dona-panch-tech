--- Habilitar enrutamiento IPv6 ---
ipv6 unicast-routing

--- Seguridad y acceso SSH (Requisito Sprint 2) ---
ip domain-name donapanchtech.local
username admin privilege 15 secret Cisco12345!
crypto key generate rsa modulus 2048
ip ssh version 2

line vty 0 4
 login local
 transport input ssh
 exit
